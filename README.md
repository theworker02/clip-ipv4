# clip-ipv4

Clip config/ipv4 key checks for twelve-factor services.

**Site:** https://theworker02.github.io/clip-ipv4/

## Install / run

```bash
git clone https://github.com/theworker02/clip-ipv4.git
cd clip-ipv4
node src/cli.js
node --test
```
